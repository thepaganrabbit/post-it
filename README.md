# Post-It App (Monorepo)

## Structure
- `postit-back/` - NestJS backend API
- `postit-front/` - Next.js frontend
- `docker-compose.yml` - Orchestrates both services

## Quick Start
docker-compose up

## Development
# Backend: cd postit-back && npm install && npm run start:dev
# Frontend: cd postit-front && npm install && npm run dev
